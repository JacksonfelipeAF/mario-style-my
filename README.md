# Jogo do Mario Style

Um jogo estilo Mario criado com HTML, CSS e JavaScript puro.

## 🎮 Como Jogar

1. Abra o arquivo `html/jogo.html` no seu navegador
2. Use **ESPAÇO** ou **SETA PARA CIMA** para pular
3. Você também pode **clicar** no jogo para pular
4. Desvie dos canos e ganhe pontos
5. A cada 5 pontos o jogo fica mais rápido

## 🎯 Funcionalidades

- ✅ Sistema de pontuação
- ✅ Aumento gradual de dificuldade
- ✅ Tela de Game Over com opção de reiniciar
- ✅ Design responsivo para mobile
- ✅ Animações suaves
- ✅ Controles por teclado e mouse/touch

## 🎨 Personalização

Você pode personalizar:
- Velocidade inicial do jogo: altere `gameSpeed` em `script.js`
- Altura do pulo: modifique a animação `jump` em `style.css`
- Cores e temas: edite as variáveis CSS
- Imagens: substitua os arquivos na pasta `img`
